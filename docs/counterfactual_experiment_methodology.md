## 0. The one thing to know first

**No language model rewrites the passage.** The counterfactual is produced by deterministic
regular-expression string substitution — roughly 250 lines of Python with no ML dependency, no
randomness, and no generation step. The header of the generator states the design
(`counterfactual_passage.py:1-15`):

> "The perturbation is deliberately *minimal and lexical*: the ground-truth answer string is
> located inside the SciQ support passage and rewritten as one of the question's own distractors.
> Everything else in the passage is left untouched, so Setting C differs from Setting B only in
> which option the context supports."

Worked illustration from that same header:

```
original passage        "Dissociation is the separation of ions ..."
correct_answer          "dissociation"
chosen distractor       "combustion"
counterfactual passage  "Combustion is the separation of ions ..."
```

This makes the perturbation exactly auditable — and it is also the source of the method's
failure on OpenBookQA (§5).

> **Standing limitation L1 (added this round).** The pipeline performs **no grammaticality check
> and no "does some option still hold" check**. A `context_dependent` or `prior_dependent` label
> can therefore rest on a perturbed passage that is not well-formed English. This affects **3.6%
> of SciQ `context_dependent` labels but 70.8% of OBQA's**. Anyone using these labels downstream
> must read **§9** first.

## 1. The three settings

Defined in the results file under `summary.settings`, verbatim:

```json
{
  "A": "no passage (question + options)",
  "B": "original passage (question + options + gold support passage)",
  "C": "counterfactual passage (gold answer rewritten as a distractor)"
}
```

Setting C is scored only for samples where the perturbation succeeded
(`counterfactual_valid = true`).

## 2. Pipeline, step by step

### Step 1 — choose the distractor to promote

`choose_distractor()` (`counterfactual_passage.py:128-168`). Fully deterministic, no randomness.
The preference order is documented in the docstring (lines 133-140):

> 1. the distractor must not already occur in the passage — otherwise the perturbed passage would
>    mention two competing targets;
> 2. it should not overlap the answer as a substring (e.g. 'oxidants' inside 'antioxidants'),
>    which would blur the option surfaces;
> 3. its word count should be as close as possible to the answer's, so the rewritten sentence
>    stays grammatically plausible;
> 4. ties are broken by the original option index.

Implemented as a sort key over `(already_present, overlaps_answer, |Δword count|, index)`, all
ascending (lines 146-167).

**Criterion 3 is the only grammaticality provision in the entire pipeline** — a word-count
proximity heuristic applied *before* substitution. See §4.

### Step 2 — locate the answer inside the passage (four tiers)

`find_substitution_span()` (`counterfactual_passage.py:96-125`) tries four tiers in order and
records which one hit (`TIERS`, line 36):

| Tier | Rule | Code |
|---|---|---|
| `exact` | the answer appears verbatim as a whole word | `_whole_word_pattern`, line 44-48 |
| `glued` | the answer's left boundary is fused to the previous word — a real SciQ artefact, e.g. `"are calledoxidants"` | `_glued_left_pattern`, line 51-53 |
| `morphological` | a plural/singular/hyphenation variant appears | `morphological_variants`, line 56-84 |
| `partial` | only a contiguous sub-phrase of a multi-word answer appears | line 115-124 |

The whole-word pattern is `(?<![A-Za-z])<escaped>(?![A-Za-z])`, case-insensitive, so `oxidant`
does not match `oxidants`. Morphological variants are generated by suffix rules only (`-ies→-y`,
`-es→∅`, `-s→∅`, `-y→-ies`, `+s`, `+es`, hyphen↔space↔∅) — no lemmatiser, no NLP dependency.

A partial match must be at least `MIN_PARTIAL_CHARS = 4` characters (line 41) "so that a
multi-word answer is never rewritten on the strength of a short function word such as 'of' or
'the'."

If no tier matches, the sample is marked `counterfactual_valid = False`, `substitution_tier =
"none"`, and is **excluded from every Setting C metric** (lines 199-213).

### Step 3 — substitute, preserving capitalisation

`_substitute()` (lines 171-181) replaces **every** occurrence of the matched surface form, using
the glued pattern when the tier is `glued` and the whole-word pattern otherwise. `_match_case()`
(lines 87-93) gives the replacement the capitalisation of the text it replaces (ALL-CAPS →
upper, Leading-cap → capitalised, else as-is). Mean substitutions per eligible SciQ sample: **1.89**.

### Step 4 — leakage audit

Lines 232-236. After substitution the generator counts:

- `residual_answer_mentions` — whole-word occurrences of the gold answer still present;
- `residual_glued_mentions` — occurrences still fused inside a longer word.

The comment (lines 232-234) explains the deliberate gap:

> "A whole-word residual is impossible after a successful pass, but the answer can survive fused
> inside a longer word ('exocuticle' keeps 'cuticle'), which is left alone on purpose: rewriting
> it would corrupt an unrelated term."

On SciQ, `n_with_glued_residual = 16` of 860 eligible samples (1.9%) retain a glued residual.
These are **not** excluded.

### Step 5 — score all three settings

`score_three_settings()` (`run_counterfactual_experiment.py:163-243`). One model is resident at a
time (4 GB VRAM); each is unloaded and the CUDA cache cleared before the next.

Both passage variants are truncated **independently** (lines 191-196), because "the substitution
can change the token count, so reusing one budget would misalign the settings".

The prompt is not a chat template — these are encoder multiple-choice models. Each option is
scored as `passage + get_bert_postfix(question, option)`, where
(`kda_tiny.py:81-85`):

```python
def get_bert_postfix(question: str, option: str) -> str:
    """Merge a question with one answer option (identical to the original repository)."""
    if question.find("_") != -1:
        return question.replace("_", " " + option + " ")
    return question + " " + option
```

The four resulting logits go through a softmax (`kda_tiny.py:161-178`). For the T5 student the
option score is instead the negative length-normalised NLL of generating the option, softmaxed —
matching the reference `KDA.get_correct_prob` (`kda_tiny.py:238-264`).

### Step 6 — classify the Setting C prediction

`classify_counterfactual()` (`run_counterfactual_experiment.py:145-153`), quoted in full:

```python
def classify_counterfactual(
    predicted_idx_c: int, answer_idx: int, counterfactual_target_idx: int
) -> str:
    """Label a Setting C prediction as context- or prior-driven."""
    if predicted_idx_c == counterfactual_target_idx:
        return "context_dependent"
    if predicted_idx_c == answer_idx:
        return "prior_dependent"
    return "unstable_other"
```

In words:

| Label | Condition | Interpretation (from the module docstring, lines 16-24) |
|---|---|---|
| `context_dependent` | argmax(C) == counterfactual target | "the model follows the context, its B-correctness is earned" |
| `prior_dependent` | argmax(C) == gold answer | "the model overrides the context with a parametric prior or an option-surface shortcut; its B-correctness is NOT evidence of knowledge dependence" |
| `unstable_other` | argmax(C) is a third option | "the perturbation broke the model without steering it" |

Three properties a reviewer should note:

1. It is a **hard argmax over three cases** — no threshold, no confidence margin, no abstain. A
   0.334/0.333/0.333 split classifies identically to 1.0/0.0/0.0.
2. It is computed **per model and again for the pooled ensemble** (lines 274-282, 335-338). The
   two can disagree; §3 shows a worked case where they do.
3. `classify_baseline()` (lines 138-143) recomputes the four A/B buckets with the same definitions
   as `categorize_kda_results.py:129-133`, deliberately duplicated rather than imported "so this
   script can run standalone".

## 3. Worked example 1 — SciQ (`exact` tier), `results_counterfactual_sciq_test_full.json` id = 1

**Question:** *What term in biotechnology means a genetically exact copy of an organism?*

| | Option |
|---|---|
| A | phenotype ← **counterfactual target** |
| B | male |
| C | clone ← **gold** (`answer_idx = 2`) |
| D | adult |

**Generation:** tier `exact`, matched text `'clone'`, `n_substitutions = 1`,
`residual_glued_mentions = 0`.

Distractor choice: `phenotype` wins on the sort key — it is absent from the passage, does not
overlap `clone` as a substring, and is a 1-word answer matching `clone`'s 1 word, so it takes the
lowest option index among the ties.

**Original passage (Setting B), opening:**

> "But transgenic animals just have one novel gene. What about an animal with a whole new genome?
> Could a **clone** , a genetically exact copy of an organism, be developed using techniques
> associated with biotechnology? …"

**Counterfactual passage (Setting C), opening:**

> "But transgenic animals just have one novel gene. What about an animal with a whole new genome?
> Could a **phenotype** , a genetically exact copy of an organism, be developed using techniques
> associated with biotechnology? …"

Note the untouched later sentences still contain *"human cloning"* and *"animal cloning"*. Those
are morphological derivatives, not whole-word matches of `clone`, so the whole-word pattern
correctly leaves them — an example of the deliberate residual gap described in Step 4.

**Primary model `Riiid/kda-mpnet-base-race`:**

| Setting | Prediction | P(A) phenotype | P(B) male | P(C) clone | P(D) adult |
|---|---|---:|---:|---:|---:|
| A — no passage | **C** clone | 0.146 | 0.007 | **0.846** | 0.002 |
| B — gold passage | **C** clone | 0.025 | 0.002 | **0.969** | 0.004 |
| C — counterfactual | **A** phenotype | **0.633** | 0.001 | 0.364 | 0.002 |

`baseline_category = both_correct` · primary `counterfactual_class = context_dependent`.

**Reading it:** the primary model knew "clone" without any passage (0.846). The gold passage
merely sharpened it (0.969). When the passage was rewritten to assert `phenotype`, the model
**followed the text** and abandoned a strong prior — so its Setting B correctness is earned, not
prior-driven, for this model.

**Ensemble disagreement.** The pooled ensemble class for this same item is `prior_dependent`,
and `kda_original = 0.5605` → `kda_adjusted_hard = 0.429`. The weaker students do not follow the
perturbation. Per-model and ensemble classes are different quantities and must be cited as such:
criterion `C3_prior_dependent` in the RQ1 pool uses the **ensemble** class.

## 4. Validity checks — what exists and what does not

This is the part most likely to be over-assumed. Verified by reading the whole generator:

**Checks that exist:**

| Check | Where | Effect |
|---|---|---|
| Answer must be locatable in the passage | `find_substitution_span`, lines 96-125 | else `counterfactual_valid = False`, excluded |
| Locator/rewriter must agree (`n_substitutions > 0`) | lines 217-230 | defensive; else invalid |
| Distractor must not already be in the passage | `choose_distractor` sort key, line 156 | preference only — **not** a hard filter |
| Distractor must not overlap the answer as a substring | line 157 | preference only — **not** a hard filter |
| Word-count proximity to the answer | line 158 | preference only |
| Minimum 4 chars for a partial match | `MIN_PARTIAL_CHARS`, line 41 | hard filter |
| Residual answer-mention audit | lines 235-236 | **recorded, not enforced** |
| Tier gate for analysis | `tier_at_least`, lines 253-256; `--min-substitution-tier` | filters at analysis time |

**Checks that do NOT exist anywhere in the pipeline:**

- **No grammaticality or fluency check.** No parser, no perplexity filter, no LLM review. The only
  provision is the word-count heuristic in criterion 3, applied before substitution and never
  verified after. §5 shows this failing on real data.
- **No "does some option still hold" check.** Nothing verifies that the perturbed passage
  actually supports the counterfactual target, or that it does not accidentally still support the
  gold answer or a third option.
- **No semantic-coherence or contradiction check** against the rest of the passage.
- **No human review** of the generated passages. `counterfactual_passages_preview_sciq.json` and
  `counterfactual_passages_preview_obqa.json` are dry-run previews; nothing records that they
  were adjudicated.

The consequence is direct: an item can be labelled `context_dependent` — the strongest evidence
the study offers that a model reads context — on the basis of a passage that is not
well-formed English. §5.2 gives such a case.

## 5. Worked example 2 — OpenBookQA, and why it behaves differently

### 5.1 The structural difference

SciQ's `support` is an **extractive** textbook paragraph: the sentence answering the question
contains the answer string verbatim, so deleting it and inserting a distractor is faithful.

OpenBookQA's `fact1` is a **deductive one-clause rule**. The question asks for an *instance*; the
fact supplies the *general principle*. They are related by inference, not string identity, so
there is frequently nothing to substitute. From `counterfactual_obqa_analysis.md` §1.2:

| Fact (`fact1`) | Question asks | Gold option | Overlap |
|---|---|---|---|
| `predators eat prey` | what a fox might eat | `bunnies` | none |
| `using less resources usually causes money to be saved` | best way to save money | `quit eating lunch out` | none |
| `fog is formed by water vapor condensing in the air` | where fog forms | `a marsh` | none |

**Tier distribution — the mechanism's transfer failure in one table:**

| Tier | SciQ (884) | OpenBookQA (500) |
|---|---:|---:|
| `exact` | 813 · **92.0%** | 42 · **8.4%** |
| `glued` | 0 · 0.0% | 1 · 0.2% |
| `morphological` | 11 · 1.2% | 5 · 1.0% |
| `partial` | 36 · 4.1% | 97 · **19.4%** |
| `none` (ineligible) | 24 · 2.7% | 355 · **71.0%** |
| **Eligible** | **860 · 97.3%** | **145 · 29.0%** |

71% of OBQA has no span to substitute, and two thirds of what survives comes through the loosest
`partial` tier.

### 5.2 A clean OBQA case — `results_counterfactual_obqa_test_full.json` id = 348

**Question:** *Little puppies are a result of:*

| | Option |
|---|---|
| A | reproduction ? ← **gold** |
| B | pet store sale ← **counterfactual target** |
| C | a begging child |
| D | evolution |

Tier `partial` (matched `'reproduction'` inside the gold string `"reproduction ?"`),
`n_substitutions = 1`.

| Setting | Passage | Prediction |
|---|---|---|
| B — gold | `reproduction produces offspring` | **A** reproduction ? |
| C — counterfactual | `pet store sale produces offspring` | **B** pet store sale |

| Setting | P(A) | P(B) | P(C) | P(D) |
|---|---:|---:|---:|---:|
| A — no passage | **0.754** | 0.074 | 0.003 | 0.169 |
| B — gold fact | **0.475** | 0.078 | 0.017 | 0.430 |
| C — counterfactual | 0.257 | **0.664** | 0.003 | 0.077 |

`baseline_category = both_correct` · primary and ensemble both `context_dependent` ·
`kda_original = 0.1674` → `kda_adjusted_hard = 0.0428`.

This one works: the perturbed fact is grammatical, asserts the target, and the model follows it.

### 5.3 The failure mode — id = 15, a `context_dependent` label on broken text

**Question:** *As gasoline costs rise, alternative fuels are being used, which means that*

| | Option |
|---|---|
| A | wind power will be expensive ← **counterfactual target** |
| D | gasoline will be needed less ← **gold** |

Tier `partial`, matched text `'gasoline will'` — a fragment spanning two words of the 5-word gold
option.

| Setting | Passage |
|---|---|
| B — gold | `as the use of alternative fuels increases , the use of gasoline will decrease` |
| C — counterfactual | `as the use of alternative fuels increases , the use of wind power will be expensive decrease` |

The Setting C text is **not grammatical English**. Yet the primary model moves D → A and the item
is recorded as `context_dependent`.

A second instance, same file: gold `panels collecting sunlight`, matched fragment `'panel'`,
producing `"a solar sun grafts converts sunlight into electricity"`.

**Why this matters for interpretation.** `context_dependent` is meant to certify that a model
*read and followed the context*. Here the model may simply be reacting to a corrupted string. The
label direction is not necessarily wrong, but its **meaning** is not what the metric name claims.
This is why the OBQA report runs an `exact`-tier sensitivity analysis
(`results_counterfactual_obqa_test_exact_tier.json`) and why its headline states the mechanism
"does not transfer": `counterfactual_passage_vs_gold` 0.310 vs
`counterfactual_passage_vs_cf_target` 0.317 on the primary model — essentially no movement.

The one comparison the OBQA report holds to, because it survives on both the degraded and the
clean `exact` subset, is that **prior-driven correct answers roughly double on OpenBookQA relative
to SciQ**: 41.5% vs 22.3% at ensemble level, 50.0% on the clean `exact` subset.

## 6. How the labels feed the adjusted metrics

From `summary.formulas` in the results files, verbatim:

```
kda_cont                      = Σ_m (1 − P_m^A) · P_m^B / Σ_m (1 − P_m^A)
kda_adjusted_hard             = Σ_m (1 − P_m^A) · P_m^B · 1[argmax P_m^C == cf_target] / Σ_m (1 − P_m^A)
kda_adjusted_soft             = Σ_m (1 − P_m^A) · P_m^B · P_m^C(cf_target)            / Σ_m (1 − P_m^A)
kda_adjusted_sample_exclusion = mean over CF-eligible q of KDA_cont(q) · 1[q is not ensemble prior-dependent]
context_verified_accuracy_with_fact = (wrong_to_correct + context-dependent both_correct) / n_eligible
```

Three variants, all implemented in `compute_adjusted_kda()`
(`run_counterfactual_experiment.py:508-596`):

1. **hard-gated** — per model, with-fact mass counts only when that model actually follows the
   counterfactual (a 0/1 indicator);
2. **soft-gated** — the indicator is replaced by the probability mass the model moves onto the
   target;
3. **sample-level exclusion** — drops questions the *ensemble* classifies `prior_dependent`
   (`n_dropped_prior_dependent`, line 579).

Variants 1–2 gate **per model**; variant 3 gates **per question on the ensemble**. Any citation of
"adjusted KDA" must say which. Example: SciQ id = 1 above is `context_dependent` for the primary
model but `prior_dependent` for the ensemble, so it is retained by variant 1's primary-model term
and dropped entirely by variant 3.

## 7. Reproduction

output paths must be set explicitly or the OBQA run will overwrite the SciQ results. Flags
available (`run_counterfactual_experiment.py:826-876`): `--data`, `--out`, `--log-file`,
`--models`, `--primary-model`, `--device`, `--limit`, `--min-substitution-tier`,
`--progress-every`, `--dry-run`, `--verbose`, `--append-log`.

```bash
# SciQ - all defaults (--data defaults to datasets/sciq/sciq_test_full.json)
uv run --active python code/ex2_counterfactual/run_counterfactual_experiment.py
```

```bash
# OpenBookQA, loosest eligibility tier (the primary OBQA run)
uv run --active python code/ex2_counterfactual/run_counterfactual_experiment.py \
    --data datasets/openbookqa/obqa_test_full.json \
    --out results/ex2_counterfactual/results_counterfactual_obqa_test_full.json \
```

```bash
# OpenBookQA, clean subset only (sensitivity)
uv run --active python code/ex2_counterfactual/run_counterfactual_experiment.py \
    --data datasets/openbookqa/obqa_test_full.json \
    --out results/ex2_counterfactual/results_counterfactual_obqa_test_exact_tier.json \
    --log-file results/ex2_counterfactual/counterfactual_obqa_test_exact_tier.log \
```

OBQA primary run, 0.478 s/question.

## 9. Standing limitation L1 — no grammaticality or answer-support validation

**Status: open. Documented, not patched.** The pipeline has deliberately not been modified; this
section exists so the gap is visible to every downstream consumer of the Setting-C labels.

### 9.1 The gap

`build_counterfactual()` guarantees exactly one thing: that the gold answer string was located in
the passage and textually replaced by a distractor. It does **not** check that:

1. the resulting passage is **grammatical**;
2. the resulting passage actually **supports the counterfactual target**;
3. the resulting passage no longer supports the **gold** answer, or any third option.

The only provision resembling (1) is preference criterion 3 in `choose_distractor()`
(`counterfactual_passage.py:139`) — "its word count should be as close as possible to the
answer's, so the rewritten sentence stays grammatically plausible". That is a *tie-breaker applied
before substitution*, it is never verified afterwards, and it is routinely overridden by
criteria 1 and 2, which sort ahead of it.

### 9.2 Worked counterexample — OBQA id = 15

**Question:** *As gasoline costs rise, alternative fuels are being used, which means that*

| | Option |
|---|---|
| A | wind power will be expensive ← counterfactual target |
| B | gas costs will rise |
| C | oil costs will be maintained |
| D | gasoline will be needed less ← gold |

Tier `partial`; the matched span is `'gasoline will'` — a two-word fragment of the five-word gold
option, which is why the substitution lands mid-clause.

| Setting | Passage |
|---|---|
| B — gold | `as the use of alternative fuels increases , the use of gasoline will decrease` |
| C — counterfactual | `as the use of alternative fuels increases , the use of wind power will be expensive decrease` |

The Setting-C string is not grammatical English, and it does not assert option A in any ordinary
sense. The primary model moves D → A, and `classify_counterfactual()` records
**`context_dependent`** — the label that certifies *"the model follows the context, its
B-correctness is earned"*.

A second instance in the same file: gold `panels collecting sunlight`, matched fragment `'panel'`,
producing `"a solar sun grafts converts sunlight into electricity"`.

### 9.3 Exposure, quantified

Ensemble `counterfactual_class` cross-tabulated against `substitution_tier` (eligible items only):

**SciQ**

| Class | `exact` | `glued` | `morphological` | `partial` | Total |
|---|---:|---:|---:|---:|---:|
| `context_dependent` | 637 | 0 | 8 | **24** | 669 |
| `prior_dependent` | 107 | 0 | 2 | **6** | 115 |
| `unstable_other` | 69 | 0 | 1 | **6** | 76 |

**OpenBookQA**

| Class | `exact` | `glued` | `morphological` | `partial` | Total |
|---|---:|---:|---:|---:|---:|
| `context_dependent` | 24 | 1 | 3 | **68** | 96 |
| `prior_dependent` | 10 | 0 | 2 | **14** | 26 |
| `unstable_other` | 8 | 0 | 0 | **15** | 23 |

The `partial` tier is where mid-phrase substitution — and therefore ungrammaticality — is
concentrated, because by construction it fires only when a *sub-phrase* of a multi-word answer
matched.

| Dataset | `context_dependent` labels resting on `partial` |
|---|---|
| SciQ | 24 / 669 = **3.6%** |
| OpenBookQA | 68 / 96 = **70.8%** |

### 9.4 Consequences for downstream use

- **SciQ Setting-C labels are safe to cite as they stand.** 95.2% of its `context_dependent`
  labels come from the `exact` tier. Re-running with `--min-substitution-tier exact` changes
  little.
- **OBQA Setting-C labels must not be cited without the tier breakdown.** Nearly three quarters of
  its `context_dependent` labels rest on the tier where the perturbation is least trustworthy.
  This is a second, independent reason for the conclusion the OBQA report already reached on
  eligibility grounds — the mechanism does not transfer.
- **The bias has a direction.** A corrupted passage makes the *gold* option less textually
  supported without making the target genuinely supported, which pushes predictions off the gold
  answer. That inflates `context_dependent` and deflates `prior_dependent`. Since
  `prior_dependent` is what criterion `C3` selects on and what the hard/soft/exclusion adjusted
  metrics discount (§6), **the OBQA `prior_dependent` count of 26 is best read as a lower bound.**
- **`results_counterfactual_obqa_test_exact_tier.json` already exists** as the clean-subset
  sensitivity run and should be preferred for any OBQA claim.

### 9.5 If this is ever fixed

Not proposed for now — the honest fix is not a filter but a change of mechanism, since for OBQA a
faithful counterfactual requires *rewriting a rule*, not substituting a span. Should it be
revisited, the minimum would be: restrict to `--min-substitution-tier morphological`; require the
matched span to cover the whole gold option rather than a fragment; and add an explicit check that
the perturbed passage entails the target. Each would shrink the eligible pool further, which on
OBQA is already only 29.0% of the split.
